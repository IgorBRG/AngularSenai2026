# Projeto Angular SENAI - Dashboard Ford

Este projeto contém o desenvolvimento do desafio de front-end utilizando Angular 19 e uma API Node.js para validação de login e busca de dados.

## Estrutura do Projeto

- `/api`: Contém a API em Node.js (Express) que fornece os dados de veículos e faz a validação de login.
- `/dashboard`: Contém o projeto Front-end construído em Angular 19.

## Como iniciar o projeto

Foi configurado um script prático para iniciar tanto o Back-end (API) quanto o Front-end (Angular) ao mesmo tempo!

1. Abra o terminal e entre na pasta `dashboard`:
   ```bash
   cd dashboard
   ```

2. Instale as dependências (caso seja a primeira vez):
   ```bash
   npm install
   ```

3. Inicie os servidores:
   ```bash
   npm run dev
   ```

4. Acesse o sistema pelo navegador no endereço:
   👉 **http://localhost:4200**
